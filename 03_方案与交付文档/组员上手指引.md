# 组员上手指引

> 仓库地址：<https://github.com/wanjiale-dev/smart-campus>
> 这份文档按顺序照做即可，全程大约 20 分钟，其中大半时间在等 Git 安装和注册验证邮件。

---

## 第一步：注册 GitHub 账号（约 10 分钟）

1. 打开 <https://github.com/signup>
2. 填邮箱 → 设密码 → 起用户名 → 邮箱收验证码
3. **用户名请用英文或拼音**，例如 `wu-jiahao`、`renxy2026`。不要用中文、空格、特殊符号，后面命令行要反复输入。
4. 注册完成后，**把用户名发给组长**，组长在仓库的 `Settings → Collaborators` 里邀请你。

> 收到邀请邮件后必须点 **Accept invitation**，否则你对仓库没有写权限，clone 下来也推不上去。

国内网络访问 GitHub 有时较慢，注册页打不开可以换手机热点试，或者先装好 Git 再回来注册。

---

## 第二步：安装 Git（约 5 分钟，只需一次）

### Windows

下载 <https://git-scm.com/download/win> 的 64-bit 安装包，一路下一步即可。安装选项保持默认，**不要**改「Adjusting your PATH environment」那一页。

装完在桌面右键 → `Git Bash Here`，能弹出黑窗口就成功了。

### macOS

终端执行 `git --version`，系统会提示安装命令行工具，点「安装」等它跑完。

### 验证

```bash
git --version
# 应输出 git version 2.x.x
```

接着配置身份（**必须做**，否则提交记录里没有作者）：

```bash
git config --global user.name "你的名字拼音"
git config --global user.email "你注册 GitHub 用的邮箱"
git config --global core.quotepath false   # 中文文件名正常显示，不打成 \344\275\240 这样
```

> `user.email` 必须和你 GitHub 账号的主邮箱一致，否则 GitHub 不会把你的提交算到你头上，contribution 图也不会有绿点。

## 第三步：拉代码（约 2 分钟）

```bash
git clone https://github.com/wanjiale-dev/smart-campus.git
cd smart-campus
```

**路径不要有中文和空格**。放在 `D:\code\smart-campus` 这种位置最省事，放桌面容易踩到中文路径问题。

## 第四步：跑起来

```bash
cd 02_程序源码
npm start
```

然后浏览器打开 <http://localhost:3000>。

几个要点：

- **不需要 `npm install`**。前后端都是零依赖，`vendor/` 里已经是各库的 dist 文件。如果你习惯性敲了 `npm install`，不会有副作用，只是没必要。
- 需要 **Node 16 或以上**。`node -v` 看一下，太老就去 <https://nodejs.org> 装 LTS 版。
- 登录账号：`admin` / `academic` / `counselor` / `teacher` / `student` / `librarian`，密码统一 `123456`。
- 只想看界面不想开服务：直接双击 `02_程序源码/frontend/index.html`，会用浏览器本地 Mock 数据。

## 第五步：开始干活

### 建自己的分支（第一次做，只做一次）

```bash
git checkout -b feature/你的模块名
```

分支名用英文，和负责的页面对应：

| 组员 | 负责页面 | 分支名 |
|---|---|---|
| 吴 | 学生信息、课程排课 | `feature/students` |
| 万 | 登录、数据总览、消息中心 | `feature/dashboard` |
| 任 | 考试考务、学工请假 | `feature/exams` |
| 王 | 图书借阅、场地预约 | `feature/library` |
| 石 | 选课、成绩 | `feature/grades` |
| 高 | 教师工作台、学生门户 | `feature/portal` |

### 每天的循环

```bash
git pull                    # 开工前先拉，别攒着
# ……改代码，刷新浏览器看效果……
git add -A
git commit -m "feat(students): 学生列表增加班级筛选"
git push
```

第一次 `git push` 会弹出一个浏览器窗口让你登录 GitHub，**在浏览器里点授权就行，不是在命令行输密码**。授权一次以后就不用再登了。

提交信息格式 `类型(模块): 说明`，类型用 `feat`（新功能）/ `fix`（修 bug）/ `style`（样式）/ `docs`（文档）。写清楚改了什么，组员和老师都能看懂。

### 改完了怎么合并进 main

`main` 分支已开保护，**不能直接推**，必须走 PR：

1. 推完分支后打开仓库，页面顶部会出现黄色横幅 `Compare & pull request`，点它
2. 标题写清楚做了什么，点 `Create pull request`
3. 点 `Merge pull request` 合并
4. 合并后分支会自动删除（仓库已开「合并后自动删除分支」）

组长（万）有管理员权限，紧急情况可以直接推 `main`，其他人必须走 PR。

## 常见报错

| 报错 | 原因 | 解决 |
|---|---|---|
| `Permission denied (publickey)` | 用了 SSH 地址但没配密钥 | 把远程地址换回 HTTPS：`git remote set-url origin https://github.com/wanjiale-dev/smart-campus.git` |
| `Authentication failed` | 密码方式已废弃，GitHub 不再支持账号密码推送 | 删掉旧凭据后重试，让它弹浏览器授权：Windows 在「凭据管理器」里删除 github.com 相关条目 |
| `Updates were rejected because the remote contains work...` | 远程有你本地没有的提交 | 先 `git pull`，有冲突按下面处理 |
| `refusing to allow an OAuth App to...` 或 `protected branch hook declined` | 你在往 `main` 直接推 | 建分支推分支，走 PR |
| `error: Your local changes would be overwritten` | 有没提交的改动挡住了 pull | `git stash` → `git pull` → `git stash pop` |
| 文件名显示成 `\344\275\240\345\245\275.js` | 中文路径转义 | `git config --global core.quotepath false` |
| 只改了一个字，diff 里整个文件都变红 | 换行符不一致 | 仓库已有 `.gitattributes`，再执行 `git config --global core.autocrlf false`，然后 `git rm --cached -r . && git reset --hard` |
| `npm start` 报端口占用 | 3000 被别的程序占了 | Windows：`set PORT=3001 && npm start`；macOS/Linux：`PORT=3001 npm start` |

### 冲突了怎么办

打开冲突文件，会看到这样的标记：

```
<<<<<<< HEAD
你本地的代码
=======
远程的代码
>>>>>>> origin/main
```

保留你要的内容，把 `<<<<<<<`、`=======`、`>>>>>>>` 这三行连同多余的那份代码删掉，然后：

```bash
git add 冲突的文件
git commit
```

实在搞不定，**不要硬来**，把 `git status` 的输出截图发群里，让组长帮你处理。硬删重来会丢掉别人的代码。
